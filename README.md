🖥️ Overview

Bandu is a lightweight cyberpunk-inspired authentication interface featuring separate Register and Sign In panels.

The design focuses on a futuristic terminal-style aesthetic using:

- Neon cyan accents
- Cyber red highlights
- Dark radial backgrounds
- Chamfered buttons
- Minimal form controls
- Responsive layout

The project is intentionally frontend-only, making it easy to use as a starting point for authentication pages, dashboards, portfolios or web applications.

📱 Responsive Design

Bandu is designed to work across different screen sizes.

Desktop

Two authentication windows are displayed side-by-side.

Mobile

The flex-based layout automatically allows the authentication windows to wrap when the available screen width becomes smaller.

---

🔐 Authentication Notice

Bandu is currently a frontend UI project.

The buttons and forms do not implement real authentication, account creation or password recovery.

For production applications, the UI should be connected to a properly secured backend implementing:

- Server-side validation
- Secure password hashing
- Session management
- HTTPS
- CSRF protection
- Rate limiting
- Secure authentication flows

Never store real passwords inside frontend HTML, CSS or JavaScript.

🧩 Customization

The main colors can be modified through CSS variables:

:root {
  --cyber-cyan: #00f0ff;
  --cyber-red: #ff003c;
  --cyber-dark: #0a0a0c;
  --cyber-bg: #121212;
  --text-gray: #a0a0a0;
}

For example, changing:

--cyber-cyan: #00f0ff;

will update the primary cyan accent throughout the interface.
